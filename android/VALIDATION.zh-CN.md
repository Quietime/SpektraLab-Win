# Android 1.3.3 验证记录

32 项 Android 原生/WebView 检查通过，使用 Android 10 x86_64 模拟器和真实 Vulkan SwiftShader 设备。检查程序是独立、同签名的测试 APK，没有放进交付程序。

覆盖：启动与手机导航；原生 Vulkan 可用；图像枚举；合成 DNG 的 LibRaw 识别、镜头配置、D65 白平衡及修正坐标取样；RGBA16 工作图像；PNG16 文件位深；调整参数确实改变像素；内容 URI 复制；中文文件名；编辑记录原子保存与重读；画布读回两个不同的实际图像采样；覆盖导入副本被拒绝、原始输入字节保持不变。

内容 URI 来自独立的只读测试提供器，文件选取 Intent 由测试框架返回。这验证了应用的 URI 读取、复制和显示链路，不覆盖各手机厂商图库或云盘提供器。导出到外部系统目录的兼容性仍取决于所选 DocumentsProvider。

前端 TypeScript、lint 和 127 项单元测试通过；4 项依赖外部 RAW 的检查明确跳过。APK v3 签名与 ZIP 对齐检查通过；ARM64 原生可执行文件的 LOAD 段按 16KB 对齐。安装后的 APK 哈希另行与交付文件核验。

模拟器没有 KVM，采用软件图形设备。旧 WebView 出现 Skia 字体栅格化崩溃，因此测试环境关闭了 GPU/OOP 字体栅格化及 GPU watchdog；WebGL2 画布仍执行真实着色器并读回像素。这些开关没有写入产品 APK，不代表真机性能或驱动兼容性。

尚未在 ARM64 实机、不同厂商相机 RAW、大尺寸图像、HDR/P3 显示及各厂商文件提供器上完成验收。不能据模拟器结果声称与 Mac 逐像素一致或所有 Android 手机上均通过。具体文件哈希和检查回执见 ANDROID133-VALIDATION.json。
